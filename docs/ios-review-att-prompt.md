# iOS 심사 탈락: 추적 권한 팝업이 나타나지 않았다

추적 권한 요청 코드를 넣었어도 실제 화면에서 팝업이 나타나는지 확인해야 한다.

## 왜 탈락했나

로또 번호 생성 도구의 2026년 10월 1일 작업 사례다. Apple은 추적 권한 요청인 ATT 팝업을 찾을 수 없다며, 가이드라인 2.1에 따라 설명과 실기기 녹화를 요청했다.

## 어떻게 고쳤나

앱이 화면에서 활성 상태가 된 뒤 권한을 요청하도록 바꿨다. 권한 결정 전에는 광고 초기화와 요청을 기다리게 하고, 분석 수집은 기본적으로 껐다. 거부해도 핵심 기능을 사용할 수 있게 유지했다.

## 어디까지 확인했나

시뮬레이터에서 첫 실행, 권한 팝업, 추적 거부 후 사용 흐름을 녹화해 **1.0.21(23)**와 함께 제출했다. 요청받은 실기기 영상은 아니었으며, 그 점을 심사 메모에 밝혔다. 이후 연령 등급 문제로 다시 거절돼 최종 승인은 확인되지 않았다.

## 다음에 확인할 점

권한이 아직 결정되지 않은 상태에서 새로 실행해 본다. 팝업 표시 시점뿐 아니라 동의 전 추적 데이터가 수집되는지도 확인한다. [Apple ATT 문서](https://developer.apple.com/documentation/apptrackingtransparency)를 기준으로 점검한다.
