# iOS 심사 탈락: Apple 로그인 로고를 직접 그렸다

Apple 로그인은 인증 기능뿐 아니라 버튼의 모양도 심사 대상이다.

## 왜 탈락했나

NES 게임 제작 앱의 2026년 9월 30일~10월 1일 작업 사례다. Apple은 로그인 버튼에 공식 리소스에서 받지 않은 로고가 사용됐다고 지적했다. 근거는 가이드라인 4였다.

## 어떻게 고쳤나

직접 만든 로고 대신 Apple이 제공하는 공식 버튼 이미지를 앱에 포함했다. 로그인 진입 화면 두 곳에 같은 이미지를 적용하고, 접근성 이름도 유지했다.

## 어디까지 확인했나

공식 이미지가 새 빌드에 들어간 것을 확인했다. **1.0(4)**를 재제출했고, 작업 기록의 마지막 상태는 심사 대기였다. 실기기 로그인 전체 과정과 최종 승인은 별도로 확인해야 한다.

## 다음에 확인할 점

Apple 로고를 비슷하게 그려 넣지 않는다. 공식 버튼이나 공식 리소스를 사용하고 크기·여백·문구도 함께 확인한다. [Apple 로그인 디자인 안내](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple)를 참고한다.
