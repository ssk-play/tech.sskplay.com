# iOS 심사 탈락: 계정 생성은 되는데 삭제가 없었다

계정을 만들 수 있는 앱이라면 계정을 삭제하는 경로도 앱 안에서 찾을 수 있어야 한다.

## 왜 탈락했나

AI 채팅 앱의 2026년 9월 23일 작업 사례다. 계정 생성은 지원했지만 삭제를 시작할 방법이 없었다. Apple은 가이드라인 5.1.1(v)를 근거로 삭제 기능과 **실기기 화면 녹화**를 요구했다.

## 어떻게 고쳤나

앱에 계정 삭제 기능을 추가하고, 실제 Google 계정의 삭제를 검증했다. 로그인부터 삭제 완료까지의 흐름을 녹화해 심사 자료로 첨부했다.

## 어디까지 확인했나

**1.0.33(35)**를 재제출하고 심사 대기 상태를 확인했다. 첨부 영상은 **시뮬레이터 촬영**임을 명시했다. Apple이 요청한 실기기 영상과는 달라 추가 자료를 요구받을 가능성이 남았다. 최종 승인 여부는 확인되지 않았다.

## 다음에 확인할 점

삭제 버튼을 누른 뒤 실제 계정이 없어지는지 확인한다. 로그아웃이나 일시 비활성화로 끝나면 삭제가 아니다. 녹화 요청을 받았다면 촬영 기기와 필요한 장면도 맞춘다. [Apple 계정 삭제 안내](https://developer.apple.com/support/offering-account-deletion-in-your-app/)를 기준으로 점검한다.
