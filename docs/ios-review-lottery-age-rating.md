# iOS 심사 탈락: 로또 도구도 도박 항목 확인이 필요했다

직접 베팅하는 기능이 없어도 로또 관련 도구라는 이유로 연령 등급 수정을 요구받을 수 있다.

## 왜 탈락했나

로또 번호 생성 도구의 2026년 10월 2일 작업 사례다. 입력창과 ATT를 수정한 빌드가 다시 거절됐다. 이번 사유는 가이드라인 2.3.6이었다.

Apple은 현금 도박과 관련된 도구·예측·정보가 포함돼 있다며, 연령 등급 설문의 **도박(Gambling)을 ‘예’**로 바꾸라고 요청했다.

## 어떻게 고쳤나

해당 항목을 ‘예’로 수정했다. 등급은 18+로 표시됐고, 코드 변경 없이 기존 **1.0.21(23)**를 다시 제출했다.

## 어디까지 확인했나

작업 기록에서 심사 대기 상태를 확인했다. 다만 설정 과정에서 한국을 포함한 10개 국가의 배포 제한 안내가 나왔다. 별도 배포 화면에서는 한국이 사용 가능으로 표시돼 실제 출시 가능 여부를 확정하지 못했다.

Apple에 실제 베팅 없이 번호만 생성하는 도구라고 설명하고, 분류 조정과 한국 배포에 필요한 조치를 문의했다. 작업 기록의 마지막 상태는 답변 대기이며, 제한 해제나 최종 승인은 확인되지 않았다.

## 다음에 확인할 점

등급을 바꾸면 판매 국가에 생기는 영향도 확인한다. 모든 로또 도구가 같은 판정을 받는다고 단정하지 않는다. 한국 등급분류번호가 필요한지는 앱의 분류와 콘텐츠 조건에 따라 [Apple 공식 기준](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/)으로 확인한다.
