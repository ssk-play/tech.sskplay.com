# iOS 심사 탈락: 키보드 때문에 링크를 붙여넣지 못했다

입력창이 화면에 있다는 사실과 사용자가 입력을 끝낼 수 있다는 사실은 다르다.

## 왜 탈락했나

로또 번호 생성 도구의 2026년 10월 1일 작업 사례다. Apple은 유튜브 링크를 붙여넣기 어렵다고 지적했다. 입력창과 조작 요소의 배치가 문제였으며, 근거는 가이드라인 4였다.

## 어떻게 고쳤나

입력창과 붙여넣기 버튼이 키보드 위에 보이도록 배치를 수정했다. 화면을 열자마자 키보드가 뜨지 않게 하고, 별도 붙여넣기 버튼도 제공했다.

## 어디까지 확인했나

실제 유튜브 링크의 복사·붙여넣기, 유효성 검사, 번호 생성까지 확인했다. **1.0.21(23)**를 재제출했다. 이후 다른 사유로 다시 거절됐으므로, 이 제출을 심사 통과로 기록하지 않는다.

## 다음에 확인할 점

키보드를 닫은 화면만 보고 판단하지 않는다. 작은 화면과 지원하는 iPad에서도 입력부터 다음 동작까지 직접 해본다. 버튼이 가려지거나 화면 밖으로 밀려나는지도 확인한다.
