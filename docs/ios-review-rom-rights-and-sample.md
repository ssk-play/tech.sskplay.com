# iOS 심사 탈락: ROM의 권리와 테스트 파일이 빠졌다

에뮬레이터 앱은 게임을 실행할 수 있다는 설명만으로 심사를 마치기 어렵다. 심사에 쓸 파일과 그 파일을 사용할 권리도 보여줘야 한다.

## 왜 탈락했나

NES 게임 제작 앱의 2026년 9월 30일~10월 1일 작업 사례다. Apple은 두 가지를 요청했다.

- **가이드라인 5.2.2:** 포함된 게임 파일의 사용·배포 권리를 설명한다.
- **가이드라인 2.1:** 기능 확인용 ROM과 Apple의 테스트 사용을 허용하는 확인서를 제공한다.

## 어떻게 고쳤나

앱에 포함된 자체 제작 샘플의 출처를 확인했다. 같은 ROM, 소스 코드, 빌드 설정, 파일 검증값, 조작 방법, 권리 확인서를 한 묶음으로 첨부했다. 로그인 없이 샘플을 실행하는 방법도 심사 메모에 적었다.

## 어디까지 확인했나

ROM의 화면·조작과 다운로드 파일 일치를 검증했다. **1.0(4)** 재제출 후 심사 대기 상태를 확인했다. 최종 승인 여부는 확인되지 않았다.

## 다음에 확인할 점

앱에 들어간 파일과 심사에 첨부한 파일을 일치시킨다. 직접 만들었다는 주장만 남기지 말고 출처와 사용 범위를 설명한다. 소스 기록은 권리 확인을 돕는 자료이며, 권리자의 확인을 대신하지 않는다.

관련 기준은 [Apple 가이드라인 5.2](https://developer.apple.com/app-store/review/guidelines/#intellectual-property)와 [2.1](https://developer.apple.com/app-store/review/guidelines/#app-completeness)을 참고한다.
